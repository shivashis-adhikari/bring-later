The first release of Bring Later: snooze a window until you need it.

Press **Win+Shift+Z** on Windows or **⌃⌥Z** on a Mac, pick a time, and the window disappears. It comes back where it was at that time, with a notification.

### Download

| | File |
|---|---|
| Windows 11, Intel or AMD | `BringLater-0.1.0-win-x64.exe` |
| Windows 11 on Arm | `BringLater-0.1.0-win-arm64.exe` |
| macOS 14 or later | `BringLater-0.1.0-mac.zip` |

Windows needs no install: run the exe and Bring Later appears in the notification area. On a Mac, unzip it and move **Bring Later** to Applications.

### Before you open it

These builds aren't code-signed, so your system will ask once:

- **Windows:** SmartScreen shows "Windows protected your PC". Select **More info**, then **Run anyway**. If Smart App Control is on, Windows blocks unsigned apps and there's no way around it except turning Smart App Control off.
- **macOS:** the first launch is blocked. Open **System Settings › Privacy & Security** and select **Open Anyway**. Then allow Accessibility access when Bring Later asks. After each update, macOS needs that access granted again; Bring Later walks you through it.

### What's in it

- Presets for the usual times, typed times like `7pm`, `tomorrow 9`, `fri 2pm` or `2h`, and a date picker.
- A list of everything snoozed, in the notification area on Windows and the menu bar on macOS, with Bring back now and Change time.
- Notifications with **Show** and **Snooze 1 hour**.
- Quitting, signing out or a crash brings every snoozed window back. If an app closes a snoozed window, you still get the reminder.

### Known limits

- This is a first release. Both apps are built and unit-tested on every change, but haven't yet been used on many machines. [Report anything odd](https://github.com/shivashis-adhikari/bring-later/issues/new).
- Snoozes don't survive a restart; windows come back when you sign out.
- macOS: full-screen windows can't be snoozed yet, and a snoozed window leaves a one-pixel sliver at the corner of the screen.
- Windows: windows of apps running as administrator can't be snoozed.

Checksums are in `SHA256SUMS.txt`.
